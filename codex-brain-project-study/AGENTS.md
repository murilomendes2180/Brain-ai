# Instruções do Codex Brain

- O cérebro é uma ferramenta para estudar e trabalhar com repositórios externos; não assuma que a pasta do cérebro é o projeto-alvo.
- Para estudar, inspecione o projeto com a menor quantidade necessária de leitura e não altere os arquivos do alvo.
- Cite caminhos de arquivos para conclusões relevantes. Separe fatos confirmados, inferências e dúvidas.
- Nunca copie, revele ou resuma valores de segredos, tokens, `.env`, chaves privadas ou credenciais.
- Não instale dependências, não faça deploy, não publique e não execute operações destrutivas.
- Não invente testes executados. Indique testes que foram executados e os que apenas parecem existir pelos arquivos de configuração.
- Propostas de melhoria não mudam automaticamente as regras permanentes.
